# ML Explorer

**Move the model, see the math.**

An interactive machine-learning laboratory for beginners: drag points, turn sliders, and watch models and metrics change.

## Run it

```bash
npm install
npm run dev      # start the dev server
npm run test     # run unit tests
npm run build    # type-check and build for production
```

Project status, architecture and decisions live in [context.md](context.md).
